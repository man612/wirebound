# Contributing to Wirebound

Thank you for your interest in Wirebound.

Wirebound is a Windows GUI wrapper for Gnirehtet. The goal is to make Android reverse tethering easier for users who are not comfortable with terminal-based workflows.

## Ways to contribute

You can help by:

- Reporting bugs
- Improving setup documentation
- Testing on different Windows versions
- Testing with different Android devices
- Improving ADB troubleshooting steps
- Suggesting UI/UX improvements
- Helping reduce package size and startup overhead

## Reporting bugs

When reporting a bug, please include:

- Windows version
- Android device model
- Android version
- Whether USB Debugging is enabled
- Whether the ADB authorization prompt appears
- What you clicked before the issue happened
- Screenshots or logs if available

## Development notes

Please keep changes focused and easy to review. Avoid large rewrites unless there is a clear reason.

## Project direction

Wirebound should stay simple, practical, and beginner-friendly. The app should help users understand the reverse tethering flow without needing to memorize terminal commands.
